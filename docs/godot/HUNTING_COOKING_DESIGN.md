### Implementation Steps

1. **Create item directories** in `/blocky_game/items/`:
   - `/wheat_seeds/`
   - `/pumpkin_seeds/`
   - `/pumpkin/`
   - `/mushroom/`

2. **For each item**, create:
   - `{item_name}.gd` - Simple item script extending item.gd
   - `{item_name}_sprite.png` - Visual sprite (can use placeholder initially)
   - `{item_name}_sprite.png.import` - Import metadata (auto-generated by Godot)

3. **Update item_db.gd** - ADD AT END:
   ```gdscript
   # Food items from farming
   _create_item({
       "name": "wheat_seeds",
       "behavior": "wheat_seeds.gd"
   })
   _create_item({
       "name": "pumpkin_seeds",
       "behavior": "pumpkin_seeds.gd"
   })
   _create_item({
       "name": "pumpkin",
       "behavior": "pumpkin.gd"
   })
   _create_item({
       "name": "mushroom",
       "behavior": "mushroom.gd"
   })
   ```

4. **Update avatar_interaction.gd** - Add drop handlers:
   ```gdscript
   func _handle_tall_grass_drop(pos: Vector3):
       # 30% chance to drop wheat_seeds (21) or berries (15) - 50/50
       # 70% chance nothing

   func _handle_dead_shrub_drop(pos: Vector3):
       # 30% chance to drop egg (13), mushroom (24), or honey (16) - 33/33/33
       # 70% chance nothing

   func _handle_pumpkin_drop(pos: Vector3):
       # 50% chance to drop pumpkin (23)
       # 50% chance to drop pumpkin_seeds (22)
   ```

5. **Update _break_block()** to call drop handlers for these special blocks

## Inventory System Integration

### Item Stacking
- Uses existing inventory stacking system
- Items added via `_add_item_to_inventory(item_id, count)`
- Stacks with existing items of same ID
- First drop goes to hotbar if space
- Overflow goes to inventory bag

### Drop Logic Flow
```
Mine block → _break_block() → Check block type
  ├─ tall_grass → _handle_tall_grass_drop() → roll 30% chance → drop wheat_seeds or berries
  ├─ dead_shrub → _handle_dead_shrub_drop() → roll 30% chance → drop egg/mushroom/honey
  ├─ pumpkin → _handle_pumpkin_drop() → roll 50/50 → drop pumpkin or pumpkin_seeds
  └─ other blocks → _add_block_to_inventory() → normal block drop
```

## Design Decisions (APPROVED)

✅ **Hybrid Approach**: Tall grass + Dead bush + Fishing traps + Companion hunts
✅ **Tall Grass**: Respawns over time (random_tickable)
✅ **Dead Bush**: Does not respawn (tracked by voxel stream)
✅ **Drop Rates**: Hidden (mystery, Minecraft-style)
✅ **Item Drops**: Use existing stacking system
✅ **Block Drops**: Never drop the block itself, only items
✅ **Item Management**: Add new items to END of database only
✅ **Debug Output**: Show block name and ID when mining starts

## Common Pitfalls Avoided

1. **Item ID Shifts**: Adding items in middle of database broke existing items
   - Solution: Always append new items to END of database

2. **Transparent Block Raycast**: Voxel raycast skips transparent blocks by design
   - Solution: Add transparency_index and collision_aabbs to voxel models

3. **Mixed Up Drops**: Item IDs didn't match drop handlers
   - Solution: Use explicit item ID comments in code (e.g., `// egg (ID 13)`)
